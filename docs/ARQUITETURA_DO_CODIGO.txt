-----------------------------------------------------------------------
4. REGRAS DE FORMATO (readconf) — o "coração" da Etapa 2
-----------------------------------------------------------------------
  Cada escopo do ini aponta para uma linha ARQUIVO (token) e tem uma
  lista de formatos reconhecidos:
    [BLOCO COMERCIAL]   -> mapas\Mapa.txt  (formatos: "mapas\Mapa.txt" etc.)
    [BLOCO MUSICAL]     -> grades\Grade.txt
    [RELOGIO COMERCIAL] -> Relogio.txt (ou Relogio<dia>::txt semanal)
    [RELOGIO MUSICAL]   -> Relogio.txt (idem)
    [AFILIADAS]         -> linhas de endereço/porta/estado

  Option = combinação (arquivo + layout) reconhecível; desconhecido =>
  "não reconhecido" e o texto original é preservado no Salvar.
  Validadores de afiliadas: "=" quando souhait pour gabaritos, porta
  1..65535, flags de desabilitado; falha => nada é gravado.

-----------------------------------------------------------------------
5. UI JUCE — DECISÕES / PADRÕES
-----------------------------------------------------------------------
  - Menus: MenuBarModel implementado pela MainWindow; itens usam ids
    confiáveis (kMenu* constexpr) e popup sensor _onMenuIndexChanged.
  - Abas: juce::TabbedComponent com TabsAtTop; a guia Códigos é a
    janela de "Lista de IDs" (menu Arquivo) e a Configuração é
    "Programação".
  - Tabelas: juce::TableListBox com ModelColumnSpan; colunas
    redimensionáveis; double-click = "id para o clipboard".
  - Diálogos: DialogWindow::showModalDialog (7 params) ao procurar
    arquivo; AlertWindow::showMessageBoxAsync para mensagens;
    MessageBoxOptions + showAsync para Salvar/Descartar/Cancelar
    (índice do botão: 0=Salvar 1=Descartar 2=Cancelar).
  - O target habilita JUCE_MODAL_LOOPS_PERMITTED=1 (CMakeLists).
  - Ícones: resources/ProgMasterIcon.png via juce_add_gui_app
    (ICON_BIG/ICON_SMALL) e juce_add_binary_data ->
    BinaryData::ProgMasterIcon_png/...Size alimentam setIcon da janela.

6. TRAPPAÇAS / QUIRKS DOCUMENTADOS (MSVC + JUCE 8.0.15)
-----------------------------------------------------------------------
  - MSVC 14.44 dá C2911 p/ definições fora da classe de aninhadas
    em alguns contextos -> cartões viraram classes friend no namespace
    app (não aninhadas), declaradas em ConfiguratorTab.h.
  - Component usa visibilityChanged() e NÃO visibleChanged.
  - TextEditor não tem setSingleLine (single-line é padrão) e
    getUndoManager() é privado -> usar undo()/redo() públicos.
  - Viewport: setScrollBarsShown(true/false, ...) e updateLayout
    foram revisados; NÃO existe setScrollBarsShownIfNeeded.
  - String NÃO tem fromUTF16 -> CharPointer_UTF16 em JuceHelpers.
  - FontOptions NÃO tem withTypefaceStyle; TextEditor::setFont usa
    juce::Font(FontOptions(...)) (o ctor Font(name,style,size) antigo
    é deprecated C4996).
  - TabbedComponent exige orientação no ctor; sem setOutlineThickness.
  - DialogWindow::showModalDialog tem 7 parâmetros exatos.
  - JUCE 8.0.15 desliga modal loops por padrão (macro acima).
